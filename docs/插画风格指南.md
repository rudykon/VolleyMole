# 五套内置插画风格

五套插画通过 Codex 内置 `image_gen` 生成，每套七张独立透明 PNG，共 35 张。原版七张插画保留，不被替换。新素材随 Python 包安装，使用时不需要 Codex、API 密钥或网络。

## 风格与素材

| 参数 | 风格 | 视觉语言 |
| --- | --- | --- |
| `default` | 原版手绘 | 原有海军蓝、奶油白和明亮运动配色 |
| `manga` | 热血漫画 | 红黄黑、墨线、赛璐璐明暗与网点 |
| `clay` | 立体黏土 | 薄荷绿、薰衣草紫、哑光手工塑形 |
| `papercut` | 层叠剪纸 | 青绿、珊瑚橙、层叠卡纸与切边阴影 |
| `ink` | 东方水墨 | 墨色笔触、朱砂与玉绿点缀 |
| `retro` | 复古丝网 | 焦橙、深青、赭黄与印刷颗粒 |

每套文件的名称与用途一致，渲染器按回合标题选择对应装饰动作；不应将装饰图理解为检测证据。

| 文件 | 用途 |
| --- | --- |
| `volley_ball.png` | 通用飞行排球 |
| `volley_save.png` | 低姿／跪姿救球 |
| `volley_set.png` | 二传与组织配合 |
| `volley_dive.png` | 飞扑与极低姿态救球 |
| `volley_receive.png` | 站姿低位接球 |
| `volley_spike.png` | 跃起扣球／长回合装饰 |
| `rank_ribbon.png` | 空白排名横幅；中文名次由程序叠加 |

## 生成不同风格的视频

```bash
.venv/bin/volleymole run \
  --video data/match.mp4 --top-k 5 --ranker rules --device cuda:0 \
  --style lively --art-theme manga --output runs/match-manga
```

把 `manga` 换为其余风格 ID 即可。四卡等推理选项可照常组合；`--top-k 10` 不需要另一套图片。`--art-theme` 仅适用于 `lively`，`classic` 不使用装饰插画。

### 已有比赛只换呈现

在原来的完整运行命令后增加 `--art-theme ink --rerun-from render`，其他视频、排名、模型和推理配置保持一致。已匹配的上游缓存可以复用；同一运行目录中的成片、片段和渲染报告会被新风格替换。如要保留多个版本，使用不同输出目录，或先备份旧成片。

已有完整、可信的 `match_manifest.json`、`edit_decision.json`、预览与跟踪证据时，也可以直接调用渲染阶段，完全不执行推理或排名：

```bash
.venv/bin/python -m volleymole.media_worker render \
  --run runs/match-top5 --style lively --art-theme ink --workers 2
.venv/bin/volleymole verify --run runs/match-top5 --style lively
```

此直接渲染命令同样会替换该目录的成片；它不更新主流程的阶段缓存或 `run_config.json`。直接渲染省略 `--art-theme` 时读取 `run_config.json`，旧运行没有此项则使用 `default`。主流程 `run` 省略该参数始终采用 `default`，所以复跑时请保留所需的参数。

风格 ID 和所用素材哈希记录在 `render_report_lively.json`。成片校验按渲染报告恢复风格；主流程将所选风格及素材内容纳入渲染缓存校验。

## 无需推理的版式预览

```bash
.venv/bin/python scripts/preview_art_themes.py --output outputs/art-themes
```

用浏览器打开输出目录的 `index.html`。每套生成六种动作标题卡、五佳／十佳的全部 15 个排名角标、五个片头角标和一个回放透明层，另有 `validation.json`。这只调用现有视频排版器，不修改原始生图 PNG，也不运行模型。

预览目录已存在对应风格时会拒绝覆盖；重复试验请换一个 `--output`。可加 `--themes clay ink` 只预览指定套装。

## 验证记录

2026-09-10：35 张原始 PNG 均通过 RGBA／alpha 与文件哈希检查；五套共 30 张动作标题卡、75 个排名角标、25 个片头层和 5 个回放层完成排版检查。79 项自动化测试通过，覆盖不同主题并发时的配色隔离、默认兼容与运行配置读取。

另用同一段已有比赛素材制作五个 9 秒实片版式短样（片头 1 秒、标题卡 3 秒、比赛 2 秒、慢回放 3 秒），全部完成解码及标题／名次像素检查。该测试未重新运行推理或排名，也不等于五次整场端到端验收。短样是本地 `outputs/` 产物，不随仓库分发；wheel 和源码包包含全部 35 张装饰素材及提示词。

## 边界与画质

风格选择会同步影响插画、横幅、标题卡底色、强调色、片头和回放提示。品牌标志、中文字体、剪辑逻辑、时长、跟球构图、音轨、720 × 1280 分辨率、30 fps 及现有 x264/CRF 参数保持原有规则。它不是对比赛录像做 AI 风格迁移。

素材原样存放于 `src/volleymole/assets/illustrated/themes/<风格>/`，未另做抠图或有损压缩。完整提示词及校验哈希见 [生成记录](../src/volleymole/assets/illustrated/themes/prompts.json)；来源说明见 [素材说明](../src/volleymole/assets/README.md)。
