# 公开排球比赛标注数据

本次只采集原作者发布的数据及原标签，不新增人工标签，不让模型生成评测真值。检索与下载日期：2026-09-12。声学模型训练数据及 SVHighlights 代理精彩评测另有独立流程；本页负责真实排球动作数据的来源与使用边界。

## 已取得的 VNL-STES

[VNL-STES 作者项目](https://hoangqnguyen.github.io/stes/)提供来自 8 场 VNL 的回合素材。事件标签包括 serve、receive、set、spike、block、score；作者先生成动作提议，再由人工纠正、补充和删除。[论文](https://openaccess.thecvf.com/content/CVPR2025W/CVSPORTS/papers/Nguyen_VNL-STES_A_Benchmark_Dataset_and_Model_for_Spatiotemporal_Event_Spotting_CVPRW_2025_paper.pdf)说明回合片段由球场可见性算法切分。因此，这些动作标签可作为已有人工校正的动作定位真值，片段首尾不能直接宣称是人工标注的完整回合边界。

原作者公开链接：<https://bit.ly/vnlvolley1>。本地保留目录：`data/public_benchmarks/volleyball/vnl_stes/`。`manifest.json` 记录来源、归档大小、原始文件 SHA-256/ZIP CRC、实际分组、样本选择、派生视频和媒体探测结果。`raw/` 中的 JSON、TXT、CSV 逐字保留；没有修正原标签。

下载实测与论文摘要存在差异，以实际文件为准：

| 维度 | 实际公开归档 |
| --- | --- |
| 归档 | 下载文件名 `vnl_1.0.zip`，根目录实际为 `vnl_1.5`；13,024,307,624 字节 |
| 训练集 | 811 个片段，实际 `events` 列表共 5,253 项，6 场比赛 |
| 验证集 | 102 个片段，600 项，波兰—美国男排 1 场 |
| 测试集 | 115 个片段，636 项，中国—波兰女排 1 场 |
| 原始划分 | 三组比赛 ID 无交集，保持原划分 |
| 素材 | 连续 JPEG 帧、标签；没有 MP4 或音轨 |
| 汇总异常 | 训练集 319 行、验证集 63 行的 `num_events` 与列表长度不同；测试集无此异常 |
| `all.json` | 共 6,623 项，不等于三组 split 合计 6,489；不混用 `all.json` 与测试集 |

这些差异由文件结构和列表计数直接得到，不是对动作内容重新标注。部分原始 `num_frames` 也与归档中实际连续帧数有一帧差异；保留所有帧并在每个样本的 `frame_count_matches_annotation` 中记录。

原 JSON 的核心结构为：

```json
{
  "video": "chn_pol_women_vnl_23_1080p/rally_000002",
  "num_frames": 306,
  "fps": 25.0,
  "num_events": 5,
  "events": [{"frame": 127, "label": "serve", "xy": [0.1383928571, 0.4732142857]}]
}
```

以上仅展示字段和一个原事件，实际评测必须读取完整原 JSON。回合帧从 `000000.jpg` 开始时，事件相对秒数为 `frame / fps`；没有原全场的起始偏移，不能虚构其全场 PTS。

## 复现采集

```bash
.venv/bin/python scripts/acquire_volleyball_benchmark.py \
  --direct --sample-count 5 --max-download-mib 1024
```

脚本通过 HTTP Range 读取 ZIP 目录与所需文件，不必下载整个 13 GB 归档。`--direct` 用于本地代理无法连接数据服务时的命令级直连。默认保存全部 1,034 个原始标签文件，并从按 `video` 排序的测试集等间隔选择 5 例；选择过程只用 ID 和列表长度，未查看动作类别或精彩程度。`--sample-count 0` 仅获取标签；`--no-video` 保留连续 JPEG，不编码 MP4。

当前样本 ID 固定为 `000002`、`000043`、`000081`、`000123`、`000166`，都来自原测试比赛。它们只用于小样本流程验证，不代表完整测试集效果。

派生 MP4 用原帧序列和标注 FPS 编码，明确为**静音视频**。不添加声音、不插帧、不改变事件标签。画面分辨率以 `ffprobe` 的实际结果为准，不把文件名中的 `1080p` 当成素材分辨率。原 JPEG 保留用于进一步核验。

## 可以与不可以评价的内容

可以将原事件帧从模型输入中完全隔离，在模型返回后计算动作类别准确性、带时间容差的事件 precision/recall/F1、预测时间误差，以及候选区间对已标注动作时刻的覆盖。评测应按事件类别和原比赛汇总，并报告当前仅覆盖一场测试比赛、五个片段。

这批数据不能独立证明五佳球/十佳球前五质量、五大囧质量、笑声归属、全场候选召回或铺垫—意外—反应的剪辑完整性。扣球、拦网、得分标签本身不等于精彩；普通失误也不等于有趣。测试集没有幽默偏好评分或完整叙事标签。

公开页说明作者取得了 Volleyball World 的素材许可，但此次归档没有独立数据 LICENSE。保留原来源与版权，不把[作者代码仓库](https://github.com/hoangqnguyen/spot)的 BSD 许可证套用于比赛视频，也不把本项目 MIT 许可证用于这些外部素材。

## SVHighlights：已跑通 40 场官方集锦代理评测

[SVHighlights 作者发布](https://github.com/leedongkyu2019/SVHighlights)包含 40 场排球完整转播对应的官方集锦对齐标签。标签体现官方编辑选段，经历原作者算法对齐和人工过滤，并非独立人工为每个回合打精彩分。数据由 `scripts/prepare_svhighlights.py` 固定到发布版本并验证 SHA-256，本地目录为 `data/public_benchmarks/svhighlights/`。

已经用作者发布的**原始 dBFS 音量特征**跑完 40 场代理标签评测，结果在 `runs/public_benchmarks/svhighlights_loudness.json`：

| 宏平均指标（每场等权） | 音量基线 |
| --- | ---: |
| 标准非插值 AP | 12.0116% |
| Hit1 | 30.0000% |
| HitK，K 为该场原正标签 bin 数 | 15.1576% |
| 原正标签 bin 比例 | 8.5512% |

这些是**音量基线结果**。尚未下载这 40 场原转播，也未运行 VolleyMole 全流程、上传、渲染或耗时测试；结果不能当成 VolleyMole 精彩榜质量。官方集锦代理还不能验证五大囧、解释正确性及整回合剪辑边界。

本评测器的 AP 按每个不同分数阈值的召回增量乘精确率求和，并将并列分数作为同一阈值处理，定义与[标准非插值 AP](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html)一致。它**不是原作者 `HL-mAP`**：[作者评测代码](https://github.com/leedongkyu2019/SVHighlights/blob/main/eval.py)使用其插值计算路径，不能将两者数值混用。Hit1 与 HitK 固定以时间更早的 bin 打破并列；HitK 严格选 K 个 bin，不把并列的全部 bin 扩大算入。

源特征适配全部留痕：`volleyball_4, 12, 13, 15, 24, 27, 28, 30, 31, 40` 的原 volume 比标签多一个末 bin，仅移除此末 bin，任何其他长度差异均拒绝。原标签覆盖以外的部分尾秒不补标。另有 314 个原 `"-Inf"` dBFS 静音值，仅在音量基线中映射为低于该场最小有限音量的值，保留排序；普通模型预测不能包含 NaN、Inf、布尔值或字符串数值。

复现音量基线：

```bash
.venv/bin/python scripts/evaluate_svhighlights.py --loudness-baseline \
  --output runs/public_benchmarks/svhighlights_loudness.json
```

模型可以提供作者格式的 JSON 列表，每行包含 `vid` 和 `pred_saliency_scores`。分数必须逐个对应原作者已裁切视频的 2 秒 bin，长度严格等于 manifest 中的 `label_bins`；不自动补零、不截断、不忽略缺失比赛。

也可以提供事件区间预测，字段如下（这是模型输出格式示例，不是新增真值标签）：

```json
[
  {
    "vid": "volleyball_1",
    "time_basis": "source",
    "background_score": 0,
    "events": [{"start_sec": 60, "end_sec": 72, "score": 0.8}]
  }
]
```

`time_basis` 必须显式为 `source`（未裁切原转播时间）或 `trimmed`（作者裁切后时间）。`source` 会减去 manifest 的 `source_trim_start_sec`，不把绝对时间直接套到标签；事件与 bin 使用左闭右开的区间，映射分数取与该 bin 有正时长重叠的最高事件分。原标签时间域外的预测会裁切并报告，未被事件覆盖的 bin 使用明确的 `background_score`。

```bash
.venv/bin/python scripts/evaluate_svhighlights.py \
  --predictions predictions.json --model-name my_model \
  --output runs/public_benchmarks/svhighlights_predictions.json
```

默认必须提交全部 40 场，重复 ID、未知比赛、错位长度均失败。只检查部分比赛时需显式增加 `--allow-subset`，报告同时列出缺失比赛，不能将部分结果宣称为完整 40 场评测。10 个测试覆盖阈值并列 AP、时间偏移、十进制时间相减误差、半开区间、未标注尾部、原特征例外及严格输入校验。
