## 验收方式

- 29 项单元测试通过，覆盖五佳/十佳所有中文名次、回合/回放/转场名次一致性、拒绝错误名次、五种动作插画选择、标志来源与派生图片缓存校验。
- 十佳真实编码测试输出 70 秒、35 个组成片段，覆盖无音频源、无追踪轨迹居中降级和模拟 API 传输故障后的规则降级。完整解码、10 张转场和 20 处回合/回放顶部名次检查通过。测试目录：`runs/verification/ranked-brand-top10/`。
- 每个转场在独立片段和最终合集的 0.5／1.5／2.5 秒与原始标题卡对照，包含标志、名次和标题，要求 RGB 像素平均绝对误差不超过 5。
- 回合及回放顶部与准确设计比较亮度误差，并在全部候选名次字形中识别最匹配名次。要求亮度平均误差不超过 4、正确名次均方误差不超过 150 且低于最近错误名次的一半。这样能区分真实错号与 YUV420 彩色边缘的压缩误差；不以放宽整幅图阈值代替名次检查。
- 转场与名次核验已接入正式 `verify_lively` 阶段及缓存签名，结果保存在 `title_card_readability.json`。
- 正式五佳成片及全部组成片段完整解码通过，源画面和原声对齐通过。5 张转场、10 处回合/回放顶部名次均通过；转场最大 RGB 平均误差约 3.19，顶部最大亮度平均误差约 2.57。入选回合与上一版的源起止时间逐一比较完全一致。

## 重新成片计时

```bash
python tools/volleyball-top-plays/run_match.py \
  --video data/样例视频/1.mp4 --top-k 5 --style lively
```

此修订的计时记录现保留为 `runs/1-top5/timing_lively_v3.json`。它统计本次命令从输入检查到成片验收的墙钟耗时；复用既有分析、追踪、候选、预览及大模型排序，不包含生图、开发调试和历史模型推理耗时，不能当作从零分析整场比赛的时间。测试机器为本机 i9-10900X，CPU/libx264 编码。

本次命令实测 **129.248 秒，约 2 分 09 秒**：准备与缓存检查 8.372 秒，渲染合成 98.022 秒，完整解码、源画音对齐及品牌/名次可读性验收 22.854 秒。其中渲染子进程内的完整回合绘制 41.283 秒，快切/回放/转场 15.622 秒，合成 40.575 秒。

成片长 **137.5 秒（2 分 17.5 秒）**，720×1280、30 fps、H.264/AAC，共 4,125 帧：原有比赛回合 102.5 秒 + 快切 5 秒 + 回放 15 秒 + 转场 15 秒。
