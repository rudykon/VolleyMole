# 排球动作理解：开发与最终测试隔离

继续使用作者发布的 VNL-STES 原始标注，不新增或修改动作标签。原始分区按比赛隔离：train 包含 6 场比赛，val 和 test 各 1 场。此前已查看的 5 条 test 片段继续保留在旧 `manifest.json` 中，不纳入本轮新增最终测试。

本轮只按 `video` ID 排序、等距取样，不参考动作类别、标签数量、时长或模型输出：

| 用途 | 原分区 | 固定样本数 | 独立目录 |
| --- | --- | ---: | --- |
| 本地动作模型适配 | train | 每场 8 条，共 48 条 | `prepared/train_adaptation/` |
| 提示词与参数开发 | val | 6 条 | `prepared/val_development/` |
| 参数冻结后的最终检查 | test | 排除此前 5 条后另取 6 条 | `prepared/test_final_sealed/` |

上述目录都位于 `data/public_benchmarks/volleyball/vnl_stes/`，各有独立 `manifest.json` 与不含事件真值的 `selection.json`。`raw/` 和 `videos/` 用相对链接复用共同源文件，评测程序可将任一 prepared 目录作为 dataset 根目录。移动数据时应保留完整 `vnl_stes/` 目录，不能只复制链接。

按开发、训练、最终测试的顺序准备：

```bash
.venv/bin/python scripts/acquire_volleyball_benchmark.py \
  --split val --sample-count 6 --prepared-name val_development --direct

.venv/bin/python scripts/acquire_volleyball_benchmark.py \
  --split train --samples-per-match 8 --prepared-name train_adaptation --direct

.venv/bin/python scripts/acquire_volleyball_benchmark.py \
  --split test --sample-count 6 --prepared-name test_final_sealed --sealed \
  --exclude-manifest data/public_benchmarks/volleyball/vnl_stes/manifest.json --direct
```

获取失败时重试同一命令，不以其他 ID 替换失败样本。已冻结的 selection 或 prepared manifest 不允许改为另一组 ID；旧的根 `manifest.json` 不会被新采集覆盖。最终测试的标注只在模型、提示词、采样和后处理参数冻结后由评测程序读取，不用于训练或调整参数。

每条视频使用公开压缩包中的完整连续 JPEG 帧，以原始 25 FPS 编码，不插帧、不改变时间起点、不生成音轨。程序逐帧验证 ZIP CRC，记录原始标注文件 SHA256、原标注行 SHA256、帧文件哈希集合 SHA256，以及完整压缩包目录元数据哈希。编码后检查帧数、平均及名义帧率、时长与无音频属性；作者声明帧数和实际文件数量有差异时，两者均保留，不改原标签。

这批标注支持六类动作的时间定位检查。它们没有精彩排名、趣味标签、声音、原完整比赛时间偏移，也没有独立人工确认的完整回合边界，因此不能单独替代集锦选择和剪辑完整性评测。原始发布信息与数据使用说明参见 [VNL-STES 作者项目](https://hoangqnguyen.github.io/stes/)。
