# 网页工作台

VolleyMole 提供中文网页界面，无需 Node.js、前端编译或额外 Web 框架。安装项目依赖后运行：

```bash
volleymole web
# 指定工作区、端口，或自动打开浏览器
volleymole web --workspace /path/to/VolleyMole --port 8787 --open
```

浏览器访问终端显示的地址，默认是 `http://127.0.0.1:8765`。未安装入口命令的源码环境可运行：

```bash
PYTHONPATH=src .venv/bin/python -m volleymole web
```

FFmpeg 和 FFprobe 必须在启动服务时的 `PATH` 中；模型与视觉素材可在网页中安装。局域网使用时，同时监听本机与指定网卡地址：

```bash
volleymole web --host 127.0.0.1 --host 172.22.13.156 --port 8787
# 源码环境
PYTHONPATH=src .venv/bin/python -m volleymole web --host 127.0.0.1 --host 172.22.13.156 --port 8787
```

同一局域网访问 `http://172.22.13.156:8787/`（将 IP 替换为实际服务器地址），本机仍可访问 `http://127.0.0.1:8787/`。也可通过 `--host 172.22.13.156` 仅监听指定网卡。局域网 HTTP 支持上传与配音编辑，不要求 HTTPS 专有的浏览器 UUID 接口。

也可以保持默认本机监听，通过 SSH 转发访问：

```bash
ssh -L 8765:127.0.0.1:8765 user@server
```

服务默认仅监听本机；局域网模式面向可信网络内共享工作区，不提供多用户登录或权限隔离。Host 校验只接受本机名称及实际连接的服务器 IP，修改接口继续验证同源请求与页面会话。

## 从录像到成片

1. 点击**导入比赛录像**，选择单段录像或整场多局模式。上传、拖入录像，或通过**从已有源片选择**按名称选取文件，无需填写目录。多局文件须命名为 `年.月.日.局号.mp4`，已有源片按比赛日期分组；上传后可点击“选择比赛日期”核对局号。
2. 选择五佳球 / 十佳球，以及竞技高光 / 趣味回合 / 双榜，然后选择成片风格。创建页模板采用等大卡片，可放大预览；手机使用紧凑双列，个人模板单独折叠。模板展示页仍保留 Bento 布局。
3. 在**确认并创建**查看录像数量、剪辑目标、风格、画面尺寸和处理模式。默认使用本地规则排名；选择趣味回合或双榜时切换到事件理解与 API 排名，确认区保留数据发送提示。排名、输出目录、设备、缓存、慢回放与 API 请求等参数在下方**高级设置**中，排错 JSON 也在此处。明确填写的选项覆盖模板设置；留空使用模板或命令默认值。
4. 创建任务，在**任务中心**查看“分析比赛 → 提取回合 → 选择高光 → 生成成片 → 检查输出”。状态来自本次实际阶段记录或明确的复用日志；没有记录的阶段不推算百分比。日志和参数默认折叠，生成视频后优先提供**播放成片**。任务串行排队；可取消、复制配置后重试，取消会终止其子进程组。
5. 首页保留排球场插画封面与导入入口；已有任务或成片后，封面收为紧凑横幅，下方显示任务列表与最近成片。**媒体库**分为**我的成片 / 比赛源片 / 我的素材**，使用真实视频截图，显示时长、画面尺寸、日期及大小，支持播放、下载、搜索、分页与列表视图。比赛源片可直接用于新剪辑，成片可打开**剪辑详情**，摘要随成片包保存。成片封面和信息在收录时由 FFmpeg / FFprobe 生成；源片与素材的信息按需读取并缓存，读取失败会明确提示，不生成示意封面。日常列表不展示后台目录、分析报告、缓存或测试数据集；分析报告及重新渲染仍可在任务详情的折叠区访问。

关闭浏览器不会停止任务。正常关闭服务器会取消未完成任务；服务异常退出后重启，会核对原进程的 PID 与启动标识：仍存活的任务重新连接监控，已经结束且无法恢复退出码的任务标记为“已中断”，不会假报成功或自动重复执行。

“任务执行：已完成”表示底层命令退出码为 0，与“成片检查通过”分别展示。后者还需要完成的验证阶段、通过的报告，并覆盖当前成片；缺失、过期或不匹配的报告不会被当成通过。可播放也不等于检查通过，识别质量与回放复核仍以对应报告为准。没有成片时，页面会说明尚在处理或未找到输出；完整日志保留用于排错。

## 媒体分类

三个分类互不混放，源片与素材按明确用途管理，成片只读取独立成片包，不按文件名、任务名称或 MP4 扩展名猜测：

- **比赛源片**：上传的完整比赛录像及已有原始录像。创建剪辑的“从已有源片选择”只读取此分类。
- **我的素材**：配音、音效、素材清单中的资源，以及通过“上传剪辑素材”明确导入的视频或音频。MP4 格式的声音素材也归这里，不混入比赛源片。
- **我的成片**：只读取 `outputs/published/<成片编号>/` 内完整的 `video.mp4`、`poster.jpg`、`manifest.json`。`runs/`、旧输出目录及其中的报告不参与成片列表扫描。即使清理后台，已收录成片的播放、封面与剪辑详情仍可用。

网页单视频和多局任务成功后自动收录本次成片；仅分析或运行失败不会收录。配音任务必须以已经收录的成片为输入，源片和素材的混音结果仍属后台产物。收录失败会显示明确原因，与底层命令退出状态分开记录。

上传入口分别指定源片或素材用途，保存到 `data/uploads/sources/` 或 `data/uploads/materials/` 下的独立批次。同名文件也不会跨分类覆盖。旧成片需从任务报告点击“收录成片”或显式运行收录命令，不会自动扫描和搬移。标准目录、H.264/AAC 格式、描述文件及迁移方式见[成片目录与格式](成片目录与格式.md)。

## 功能与入口

| 功能 | 网页入口 | 对应命令 |
| --- | --- | --- |
| 单视频五佳 / 十佳 | 创建剪辑 → 单段录像 | `run` |
| 多局分组、扫描日期、统一排名 | 创建剪辑 → 整场多局 | `match` |
| 独立动作、跟踪、球员、共享推理 | 专业工具 → 独立模型推理 | `infer` |
| 画面、音频、时间轴及字幕验证 | 任务输出 / 专业工具 → 成片验证 | `verify` |
| 慢回放复核与边界设置 | 任务输出 / 专业工具 → 慢回放复核 | `review-replays` |
| 添加本地配音 | 配音时间点编辑器 → 本地配音混音 | `meme-audio` |
| 离线准备、限次 API 选梗、配音输出 | 专业工具 → 智能配音导演 | `meme-director prepare/run` |
| 模型下载、校验、导入 | 模型与资源 / 专业工具 | `models` |
| 视觉素材下载、校验、导入 ZIP | 模型与资源 / 专业工具 | `assets` |
| 模板新建、编辑、导入、导出 | 成片模板 / 专业工具 | `templates` |
| 从已有运行导出模板 | 专业工具 → 模板 → 导出 | `templates export --from-run` |
| 回合参数、评分权重编辑 | 专业工具 / 工作区设置 → 算法编辑器 | `run/match --config` |
| API 地址、模型、密钥 | 工作区设置 | `llm_api.json` |

所有正式命令与公开参数的表单从项目实际 `argparse` 定义生成。开发用的内部参数（例如事件帧缓存）不暴露。研究评测、训练和发布脚本仍见[脚本目录](../scripts/README.md)。

## 模板、配音和资源

**模板**：五套内置设计提供实际图片预览。编辑内置模板后以新名称保存；已存在的个人模板也不覆盖。可导入 JSON 后在表单中调整，也可以导出当前配置。模板只包含可移植的剪辑、风格与配音设置，不包含录像路径、设备或密钥。

**配音计划**：选择已有成片，添加声音素材、成片插入时间、素材起止时间和音量。保存时检查音频存在、短句长度、成片边界、重叠与数量限制。保存成功后自动填入混音工具；混音会输出新文件，并验证编码画面与视频时间戳未改变。计划允许零处配音。

**模型与资源**：页面上的“文件已找到”只表示存在及大小相符，点击“校验”才会检查完整 SHA-256。网页下载模型默认保存到 `models/`，视觉素材默认保存到 `data/visual-assets/`，后续任务自动使用。自定义目录可以在专业工具中指定；已有 `VOLLEYMOLE_ASSETS` 环境设置仍然优先。

## 文件与安全边界

- 上传按 4 MiB 分块写入临时文件，完成后原子发布，单文件最大 50 GB，不覆盖同批次同名文件。上传使用实际文件扩展名；断开时删除未完成的临时文件。
- 文件浏览、预览、下载和显式任务路径限制在工作区内；拒绝路径穿越、逃逸符号链接、程序目录和常见凭据文件。系统字体可作为只读字体参数使用。工作区外的录像应先复制到工作区。
- API 密钥只保存在本机 `llm_api.json`，文件权限为 `0600`。读取设置只返回是否已配置，留空保留原密钥。报告、文本日志会隐藏常见凭据字段；文件服务不提供凭据文件下载。
- 修改接口验证本页会话 token、Host 与 Origin；任务通过固定命令及参数数组启动，不执行用户提供的 shell 命令。
- 已收录成片、比赛源片和素材支持 HTTP Range 和 HEAD，浏览器可拖动播放；后台 `runs/` 视频及未收录输出不通过普通媒体接口展示。源录像是否能直接播放取决于浏览器对其编码的支持；生成的 H.264/AAC 成片可正常预览。
- 网页任务保存在 `.local/web/`，上传文件按用途保存在 `data/uploads/`，可视化编辑器产物保存在 `data/web-config/`。这些目录均不进入源码发布。

## 开发验证

```bash
PYTHONPATH=src:tests .venv/bin/python -m unittest -v test_web test_web_library test_web_experience test_published_films
PYTHONPATH=src:tests .venv/bin/python -m unittest discover -s tests -p 'test_*.py'
node --check src/volleymole/web/static/app.js
```

网页测试包含真实本机 HTTP 请求、上传、分段读取、凭据保护、模板冲突、命令参数映射、真实 CLI 子进程、队列取消及服务恢复。测试需要允许监听本机随机端口。UI 静态资源、设计预览与服务器代码随 wheel 一起发布。
