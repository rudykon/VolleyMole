# 素材安装与分发

插画、标题字体、品牌 PNG 和五套转场材质通过 [assets-v1 Release](https://github.com/rudykon/VolleyMole/releases/tag/assets-v1) 发布，完整 ZIP 约 90 MiB。模型和比赛录像使用独立的获取流程。源码和 wheel 只保留程序、素材清单、许可及生成来源记录；README 预览图存放在仓库的 `docs/images/`。

## 安装与检查

```bash
.venv/bin/volleymole assets fetch
.venv/bin/volleymole assets verify
```

默认安装位置为 `${XDG_CACHE_HOME:-~/.cache}/volleymole/assets/assets-v1/`。命令校验 ZIP 大小与 SHA-256，再校验每个解压文件。所有文件通过后才将临时目录整体移到安装位置；重复执行会离线复用已校验的版本。

程序按以下顺序查找素材：

1. 环境变量 `VOLLEYMOLE_ASSETS` 指定的素材根目录。
2. 用户缓存中的固定素材版本。
3. 开发者原有的完整 `src/volleymole/assets/` 本地素材。

这里的根目录直接包含 `fonts/`、`illustrated/`、`transitions/` 等子目录。环境变量需在启动程序前设置，子进程会继承它。渲染不会自动访问网络。

## 自定义位置及离线安装

```bash
export VOLLEYMOLE_ASSETS=/path/to/volleymole-assets/assets-v1
.venv/bin/volleymole assets fetch
.venv/bin/volleymole assets verify
```

也可以在联网电脑上从 Release 下载 `volleymole-assets-v1.zip`，拷贝到目标机器后运行：

```bash
.venv/bin/volleymole assets import-file /path/to/volleymole-assets-v1.zip
```

三个子命令均支持 `--directory /path/to/assets-v1`。指定目录不会修改用户配置，后续渲染仍须设置 `VOLLEYMOLE_ASSETS` 指向该目录。

如果现有目录损坏或缺文件，命令会报出不匹配项并保留目录。可以先备份并移走它，再重新安装；也可以使用新的目录。下载失败留下的临时文件会自动清理。校验命令不执行下载。

## 版本和许可

当前代码固定读取 `asset_manifest.json` 指定的版本和哈希，不追随可变的 `latest` 下载地址。代码更新而素材不变时可以复用同一个素材版本；素材有变化时发布新版本并更新清单。

Release 同时提供 `asset_manifest.json` 和 `SHA256SUMS`。字体原始 OFL 许可、来源说明和插画生成记录保留在包内；项目代码的 MIT 许可不改写第三方字体许可。来源见 [THIRD_PARTY.md](../THIRD_PARTY.md)。

维护者构建命令（需要本地完整素材）：

```bash
python3 scripts/build_asset_bundle.py --version assets-v1 --output dist/assets-v1
```

该命令生成 ZIP、外部清单及校验文件，并更新源码内的固定清单。它不会上传文件。发布时将三个附件上传到同名 Release；已发布版本的附件保持不变。完整包包含原图和字体，仓库预览图只用于文档展示。
