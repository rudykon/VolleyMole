# 梗使用条件与 API 导演

先识别动作和结果，再选梗和时机。默认四球最多两处、每回合最多一处、同一梗不重复、配音区间至少相隔 6 秒。允许只放一个或者完全不放，不设“必须用满”的配额。

## 每个梗的使用条件

| 梗 | 触发条件 | 禁用情况 |
|---|---|---|
| 开炮 | 只用于明确势大力沉的重扣：充分挥臂、强力触球、出球迅猛须同时可见。跳起来或球落地不能单独证明力度。 | 吊球、轻拍、抹球、滚吊、二传、发球、救球和力度不明一律禁用。 |
| 救救我救救我 | 明显来不及、极限追球、扑救或多人接力抢救。 | 普通垫球、从容接球、二传和真实受伤求助。 |
| 啊（土拨鼠尖叫） | 突发、夸张且无受伤的险情或离谱救回之后，短促使用。 | 普通球、疼痛、真实受惊或持续尖叫盖住比赛。 |
| 牛逼 | 有明确成功结果的高难扣杀、极限救球、单人拦网或连续高质量对抗。 | 普通得分、结果未明和靠对方明显失误得分。 |
| ***退钱 | 非受迫的明显离谱失误，且有轻松自嘲或同伴友好反应；仅使用已消音版本。 | 正常攻防失误、判罚争议、受伤或针对具体人的辱骂。 |
| 电视没信号 Bi~ | 意外失误后有明显愣住或喜剧停顿，使用短而轻的提示音。 | 进行中的球、正常停顿、用长蜂鸣掩盖现场声。 |
| nice | 干净利落的救球、巧妙吊球、落点处理、拦网或配合成功之后。 | 动作失败、结果不明；不把普通每一球都夸一遍。 |
| 黑人问号 | 画面中确有意外事件和困惑反应，由比赛情节触发；仅音频模式无合适素材时跳过。 | 不能由球员肤色、外貌或身份触发，不能为了贴图增加分屏。 |
| 哈哈哈哈（曹操） | 回合结束后有明确欢乐、自嘲或友好庆祝，短笑声点缀。 | 嘲笑对手、受伤或尚未结束的攻防。 |
| 真香 | 已有明确的先否定、后成功反转叙事，且前情由编辑提供；不能靠单个好球脑补。 | 没有前情、没有反转、只是好球或从球员表情猜测内心。 |
| 我的天哪 | 濒临落地却救回、连续救险后逆转或出乎意料的成功结果。 | 普通得分、仅有高球弧线或结果不明。 |
| 一个字，绝！ | 落点、技巧或救球处理特别漂亮，完整结果已经出现之后。 | 普通击球、结果未出现，或长台词挤掉下一次触球。 |
| 刺激 | 上下文足以证明连续多拍紧张攻防、反复险救，结束后作为收尾。 | 只看几帧就猜长回合、单次普通进攻、还在击球时抢声。 |

可执行规则位于 `src/volleymole/meme_policy.json`；提示词位于 `src/volleymole/prompts/meme_director.md`。负面条件优先于正面条件；受伤、明显痛苦、羞辱和判罚争议全局排除。未取得的素材不参与自动选择，不能临时替换成另一个不贴切的梗。当前实际入库可播放的素材是 nice 和开炮，其他 11 个已配置条件，仍需相应本地素材。

## 模型如何决定时机

1. 从入选动作的原视频提取真实时间戳画面，默认以 12 帧/秒、1280 像素宽抽样。目标触球前后 0.6 秒保留密集帧，外围上下文间隔约 0.25 秒，并保留两端。图像印有帧号与时间；全景下方的局部来自同一原始帧，不是另一个时刻。请求最后重示目标参考帧，帮助模型围绕正确动作判断。只发送抽样 JPEG 和规则，不发送原视频或音频。
2. 模型返回 `use` / `skip`、动作种类、力度、可见事实及引用帧、所选梗、配音开始对应的画面，以及触球帧。不能仅根据“跳起”“进攻”或得分猜重扣，不能根据慢放速度判断实际力度。
3. 本地检查必需条件、禁用条件、证据引用和置信度门槛。开炮还要求扣球动作、明确重力度、挥臂→触球→至少三帧出球轨迹；任何一项不足就跳过。用户的吊球纠正具有优先级，即便模型自信地误判重扣，也不能给这个动作加开炮。
   对通过以上检查的开炮候选，再调用一次独立动作观察：只发送目标前后的七张已准备帧，不提供先前答案或梗条件。两次判断须都支持明确重扣；缺少复核、力度不明或判断矛盾时不放行。这项额外请求计入同一个 `max-calls`；额度不足时保持未完成，不自动提高上限。独立核验的真实效果仍待实测，不能视为正确性保证。
4. 将源视频时间映射到已有慢放的成片时间。保护所有已列出的触球及已知动作峰值前后 0.15 秒；完整台词不能跨出这段慢放。依据结果的赞叹必须等结果证据出现后开始。
5. 全片去重并限制密度，生成 `audio_plan.json`。被拦截的结果记录原因，不偷偷换梗、不补第二个梗。没有适配项则保留原声。

模型自报置信度不等于实测准确率。规则可以拦截明确矛盾和无证据的输出，但不能保证模型永远正确；新视频上的动作、力度和配音听感仍需实际验证。

## 命令与本地文件

先准备已有成片及回放映射的 manifest：

```json
{
  "version": 1,
  "video": "approved.mp4",
  "assets": "meme-assets.json",
  "clips": [{
    "id": "rally_01",
    "source": "original_match.mp4",
    "source_start_sec": 10.0,
    "source_end_sec": 13.0,
    "peak_sec": 11.0,
    "context_start_sec": 9.4,
    "context_end_sec": 13.6,
    "output_start_sec": 20.0,
    "output_end_sec": 24.5,
    "playback_rate": 0.6666666666666666,
    "editor_constraints": {"action": "tip", "forbidden_memes": ["kaipao"]}
  }]
}
```

`source_*` 是原视频内的秒数，`output_*` 是已完成成片中的回放区间。每个上下文最长 8 秒。路径相对 manifest 解析。可选的 `focus_bbox: [left, top, right, bottom]` 使用旋转校正后、0 至 1 的显示坐标，可从已有跟球构图或目标定位导出；未提供时使用当前序列的运动区域辅助放大，始终保留全景。它不是动作类别或力度标签。`editor_constraints` 为可选的明确人工纠正，必须随对应原片与区间绑定，不能搬到其他录像。

素材清单示例，路径相对素材清单解析：

```json
{"assets":[{"id":"nice","kind":"audio","ready":true,"path":"nice.wav",
             "source_start_sec":0.0,"source_end_sec":0.84,"rms_db":-20}]}
```

仅在原素材确实包含完整台词时使用该区间；示例时间不能直接套到其他素材。退钱素材还必须标记 `censored: true`。

```bash
# 仅本地抽帧、准备规则和请求；不读密钥、不联网。
.venv/bin/python -m volleymole meme-director prepare   --manifest data/meme-review-manifest.json --run runs/meme-review

# 获得本轮调用授权后执行；最多 4 次，无自动重试。
.venv/bin/python -m volleymole meme-director run   --run runs/meme-review --llm-config llm_api.json --max-calls 4   --render-output outputs/with-api-memes.mp4
```

默认使用项目同一 AiHubMix 服务的 `qwen3.5-35b-a3b`，走兼容 Chat 接口，以降低调用费用。完整 JSON 结构同时放入提示词，避免网关降级结构化输出时丢失字段约定。此默认选择不代表视觉质量已通过跨视频验收；不确定或不满足梗条件时仍然跳过。可以显式选择其他模型，Gemini 只在明确指定 `--protocol gemini --model gemini-3.1-pro-preview` 时使用；没有自动昂贵模型兜底。密钥只在实际 `run` 时从配置或 `VOLLEYMOLE_API_KEY` 读取，不进入抽帧、提示词、缓存或日志。

默认输出上限为 8192，推理等级为 high；可通过准备命令的 `--max-output-tokens` 和 `--thinking-level` 显式配置。只有当前已入库且未被编辑禁用的梗及其规则进入模型请求，全部 13 种规则仍参与本地检查。这样避免无素材可用的梗干扰判断。

显式 Gemini 路线采用有大小上限及总时限的增量 SSE 解析器；默认 Chat 路线采用有上限的完整响应解析。另有 `chat_stream.py` 兼容流式实现，已用于本次 Kimi 长请求实验，尚未自动替换所有 Chat 调用。流式路线区分连接建立、流式读取与最终 JSON 解析。记录 HTTP 状态、底层异常类、首字节/首段回答时间、收包数量、输出结束原因及模型用量；不记录密钥、请求内的图片数据或思考文本。`MAX_TOKENS`、中途断流及未正常结束的响应均不算成功。失败时保存脱敏的最终回答片段和具体校验错误，便于排查；不能将它作为配音决策继续使用。

每个请求在发送前持久化预占次数，失败即停，重启不会重置额度或重发已消耗请求；同目录不能提高 `max-calls`。已成功的相同请求可以复用。源成片、素材、规则、抽样画面、提示词、模型设置与代码均绑定哈希；变化后需重新准备。实际模型调用范围与次数以当前用户授权为准，命令参数不会自动授予授权。
