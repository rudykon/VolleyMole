# 本地声音模型部署

已安装 PANNs `Cnn14_DecisionLevelMax`，使用作者已经在 AudioSet 上训练的 527 类声音事件权重；本次没有重新训练，也没有新增人工或模型伪标签。作者明确将该模型用于逐帧声音事件检测，而普通 `Cnn14` 是整段声音分类模型，不能代替本接口。[作者说明](https://github.com/qiuqiangkong/audioset_tagging_cnn#sound-event-detection-using-pretrained-models)

`run` / `match` 在模型目录中发现以下两个文件时会自动启用：

```text
models/audio/panns_cnn14_sed.pt
models/audio/panns_cnn14_sed.labels.json
```

模型目录按 `--models`、`VOLLEYMOLE_MODELS`、项目默认 `models/` 的顺序确定。可用 `--no-sound-model` 显式关闭；也可用 `--sound-model` 与 `--sound-labels` 指定另一对本地文件。默认在 CPU 推理，需要时指定 `--sound-device cuda:0`。运行时不联网下载权重。

若同目录存在与模型同名的 `panns_cnn14_sed.thresholds.json`，程序会读取独立开发集得出的类别发现阈值；也可用 `--sound-thresholds` 显式指定。侧文件必须绑定当前 `.pt` 与类别 JSON 的 SHA256，每个阈值必须属于模型已有类别且在 `[0, 1]` 范围内。哈希不匹配会拒绝运行，避免将另一模型的阈值误用于当前输出。未配置的类别继续使用 `0.5`。这只改变候选发现门槛，不改变或校准网络原始概率；缓存同时记录侧文件哈希和推理设备。

## 可复现安装

使用项目环境运行：

```bash
.venv/bin/python scripts/install_sound_model.py
```

如果本地代理不可用但可以直连官方站点，加 `--no-proxy`。已有原始权重与官方类别 CSV 时可完全离线导出：

```bash
.venv/bin/python scripts/install_sound_model.py \
  --checkpoint 'models/audio/Cnn14_DecisionLevelMax_mAP=0.385.pth' \
  --labels-csv models/audio/class_labels_indices.csv \
  --verify-audio data/public_benchmarks/audio/esc50/audio/1-1791-A-26.wav
```

安装器在加载前检查 SHA256 与作者发布的 MD5，采用 `weights_only=True` 载入，严格检查全部网络参数，然后使用 `torch.jit.script` 导出可变长度模型。导出只依赖项目已有的 PyTorch，不需要额外安装旧版 `torchlibrosa`。启用 `--verify-audio` 时，验证完成后才发布最终 `.pt` 文件。

作者原始检查点为 327,428,481 字节，MD5 是 `70539c43c18b6a289b3199c503a82c5a`；Zenodo 记录注明权重采用 CC BY 4.0。[作者权重与许可](https://zenodo.org/records/3987831)

固定 SHA256：

```text
dd3b4043a87d4ec13df8082c0fcfee3fb5084151808e47e060987a95eabdd142
```

本次官方传输过慢，实际通过固定版本的公开镜像下载，并确认文件与作者校验值完全一致。镜像版本为 `5e740f6f84d224b8678d25313e69b2a2ae9cafff`；hf-cli 遇到 TLS 失败后使用 curl 续传完成。[镜像文件与 SHA256](https://huggingface.co/spaces/pauldarvin/wav_SED/blob/5e740f6f84d224b8678d25313e69b2a2ae9cafff/panns_data/Cnn14_DecisionLevelMax.pth)

## 验证与适用范围

已使用 ESC-50 原始笑声音频检查 0.08、0.32、1.25、2.73、5 秒输入，导出模型与未导出网络的输出逐项一致，时间范围均未超出源音频。详细记录见安装目录中的 `panns_cnn14_sed.manifest.json`；这项验证证明模型导出与时间协议正确，不代表比赛识别准确率。公开标签上的完整识别评测见[声音公开评测](声音公开评测.md)。

另用作者原始 `models.py` / `pytorch_utils.py` 与 `torchlibrosa 0.1.0`、`librosa 0.11.0` 做了独立核对：原数据集中笑声、掌声、狗叫各一条，分别检查上述五种长度，共 15 组。谱图、logmel 和最终逐帧概率与已部署模型完全一致，最大绝对误差均为 0。报告保存在 `runs/public_benchmarks/panns_reference_parity.json`，复跑脚本为 `scripts/verify_sound_model_reference.py`；引用代码文件有固定 SHA256 校验，参考依赖安装在临时隔离目录中。

输出每 10 ms 一帧，但这是由间隔 320 ms 的 CNN 输出插值得来，不能作为精确排球触球时刻的独立证据。小于 320 ms 的输入会在模型内部补零，并将结果裁剪回原始时长。模型提供 `Laughter`、`Cheering`、`Applause`、`Clapping` 等通用声音类别；声音属于本场还是邻场、是否与画面事件相关，仍由后续音画理解确认。声音置信度本身不直接增加竞技排名。
