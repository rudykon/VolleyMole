# 公开声音数据与可复现评测

本地使用原作者已有人工标签，不要求用户标注，不由助手听音重标，也不把模型预测当作真值。已下载 [ESC-50 官方仓库](https://github.com/karolpiczak/ESC-50)固定提交 `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6` 的全部 2,000 段音频（每段 5 秒、50 类，每类 40 段）。原作者的数据说明和逐片授权保存在数据目录中的 `README.md`、`LICENSE`；数据集整体为 CC BY-NC 3.0，ESC-10 子集另按 CC BY，不能把整个数据集声明为商业可用。

## 数据与复现

```bash
.venv/bin/python scripts/prepare_public_audio.py
.venv/bin/python scripts/evaluate_sound_events.py --device cuda:0
```

没有 GPU 时使用 `--device cpu`。声音权重通过 `scripts/install_sound_model.py` 部署，具体参数以该脚本的 `--help` 为准。评测默认读取 `models/audio/panns_cnn14_sed.pt` 和同目录 `panns_cnn14_sed.labels.json`。

本地文件：

- `data/public_benchmarks/audio/esc50/meta/esc50.csv`：原始人工类别、原 fold、Freesound 源 ID，未改动。
- `data/public_benchmarks/audio/esc50/manifest.json`：来源 URL、固定提交、许可、下载包与逐片 SHA-256、原始分区及源重叠审计。
- `runs/public_benchmarks/esc50_panns.json`：已完成的完整统计与限制。
- 同目录 `.predictions.jsonl`、`.identity.json`：逐片预测及模型、标签、代码、数据指纹。中断后复用匹配缓存；模型或数据变化须换输出路径。

## 评测协议

生产使用的 `LocalSoundDetector.framewise` 提供逐帧概率，本评测仅对时间维取最大值，将 `laughing → Laughter`、`clapping → Clapping` 固定映射到官方模型类别。对全部 2,000 段分别计算笑声与掌声的一对其余类别 AP、AUROC，并另外报告固定阈值 0.5 的检出、漏检和标签分歧。没有用测试集训练、选阈值、挑容易样本，也没有改成模型自制标签。

每个目标类别各有 40 段正例及 1,960 段按原单类别标签定义的名义负例。ESC-50 不是详尽多标签标注，其他类别录音中可能有未标注的背景笑声或掌声。因此“误报”计数准确含义是**与原单类别标签的分歧**，不能宣称每个分歧都经过人复核证实为错误。

保留原 5 个 fold，每个 400 段。实际原始 CSV 中有 4 个源 ID 跨 fold：`131943`、`134049` 跨 2/3，`209698`、`234879` 跨 4/5。脚本记录这一事实，不静默修改官方分区。本次所有 fold 都用于固定预训练模型评测，不是重新训练后的五折交叉验证；今后若训练，必须单独处理这些源重叠。模型预训练数据与本评测的精确内容重叠尚未审计。

## 2026-09-12 实测结果

2,000/2,000 段完成、0 失败。设备为 RTX 3090，Torch `2.11.0+cu128`，CPU 线程数 4；本次运行从加载、解码到统计共 52.72 秒，其中逐片解码与推理合计 47.58 秒，未复用预测缓存。评测的 TorchScript SHA-256 为 `abff8248ddf67fd846b1230f7a502717e83c407dbd64a2acc9a810a86a1776e7`。

| 类别 | AP | AUROC | 0.5 阈值检出 | 漏检 | 名义负例中的标签分歧 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 笑声 | 0.6851 | 0.9938 | 1/40 | 39/40 | 1/1,960 |
| 掌声 | 0.9243 | 0.9983 | 0/40 | 40/40 | 0/1,960 |

结果表明模型对目标类别已有排序信号，但**默认 0.5 阈值在本数据上的召回远远不足**。作者原始网络代码与 torchlibrosa 前端的独立数值比对已排除移植误差，详见 `runs/public_benchmarks/panns_reference_parity.json`。保留这次结果作为固定基线；下面的阈值仅由独立 FSD50K 原开发标签确定，没有使用 ESC-50 标签选阈值。唯一笑声基线标签分歧的原类别是 `crying_baby`，这里只报告分歧，不新增人工判定。

## 独立 FSD50K 开发集阈值校准

预先固定的协议为：只取 [FSD50K 原 `dev.csv`](https://zenodo.org/records/4060432) 中作者标为 `train` 的记录，排除全部 ESC-50 Freesound 源 ID，然后按数值 ID 升序，对 `Laughter`、`Clapping`、`Cheering` 各取前 40 个原标签正例和前 120 个不含该目标标签的名义负例。保留全部原多标签、AudioSet MID、原分区及逐片作者和许可。三个类别去重共 **236 段**，没有新增标注，没有把 FSD50K eval 改称 train，也没有重新训练网络。

236 份 WAV 全部通过官方 ZIP 中央目录的 CRC32 与原大小核对，并记录 SHA-256；28 份来自官方 Zenodo 范围下载，208 份来自 [Fhrozen/FSD50k 原 WAV 镜像固定提交](https://huggingface.co/datasets/Fhrozen/FSD50k/tree/ccf1acaff12f3f4a4c10052dddafbb6d22152c9b/clips/dev)。镜像文件同样逐片匹配官方 CRC，没有采用有损转码文件。数据共 132,083,924 字节 WAV；逐片许可分布为 CC BY 3.0 114 份、CC0 26 份、CC BY-NC 3.0 68 份、CC Sampling+ 1.0 28 份，应保留这些原许可和署名信息。

分别对每类固定 160 段开发样本的原标签和时间最大概率，选择令 `F2 = 5TP / (5TP + 4FN + FP)` 最大的阈值；精确并列时取更高阈值。开发指标是在同一校准样本上的拟合效果，不是独立测试结论。固定 ID 抽样保证可复现，不代表真实比赛的类别比例。

| 类别 | 选定阈值（约） | 开发集检出 | 名义标签分歧 | 开发 F2 |
| --- | ---: | ---: | ---: | ---: |
| 笑声 | 0.00159638 | 37/40 | 2/120 | 0.9296 |
| 掌声 | 0.000635771 | 36/40 | 0/120 | 0.9184 |
| 欢呼 | 0.000208263 | 38/40 | 3/120 | 0.9453 |

完整精度的阈值在 `models/audio/panns_cnn14_sed.thresholds.json`，绑定模型和类别 JSON 的 SHA-256，由运行流程自动加载。这些数值是**候选发现阈值，不是校准后的可信概率**。没有对应校准的其他模型类别仍使用默认阈值。

使用这些固定开发阈值复用原 ESC-50 概率，笑声与掌声都检出 40/40；对应名义负例分歧分别为 77/1,960、68/1,960，按原单类别标签计算的精确率分别只有 **34.2%、37.0%**。因此召回改善仍伴随干扰候选，必须继续做音画关联复核，不能直接据此认定得分、囧事或给榜单加分。此前已经看过 ESC-50 的基线，因此这里明确是**非盲的后续检查**，不能包装成新的盲测。ESC-50 无欢呼正例，不能提供欢呼的独立测试结果。

## 能评价什么

这组数据能评价笑声、掌声的**片段级分类**及多类环境声音干扰；不能评价声音发生边界、邻场声音归属、有效触球、欢呼与得分关系、笑声与画面事件的关联。没有强时间标注时，脚本不输出事件定位精度。ESC-50 没有欢呼和语音正例，两项报告为未知，不能用本结果宣称它们通过验收。

真实比赛精彩度、趣味度、前五质量与铺垫／意外／反应完整性也不属于声音数据的标签范围。评测耗时仅为声音模型加载、解码、推理和统计，不是完整影片分析或“总耗时增幅 25%”目标的验证。

FSD50K 还提供原 eval 10,231 段，其中笑声标签 253、掌声 188、欢呼 109、语音 785。其官方 334.7 KB ground-truth 包已经核对发布 MD5，保存到 `data/public_benchmarks/audio/fsd50k_metadata/`；**这部分 eval 音频尚未下载或评测**。已完成的 236 段仅属于前述独立 `dev/train` 校准，不包含 eval。
