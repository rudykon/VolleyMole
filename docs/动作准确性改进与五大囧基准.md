# 动作准确性改进与五大囧基准（2026-09-12）

这轮完成了真实原标注数据上的本地时序动作模型训练、同一封存样本的对照评测、动作候选接入，以及可实际填写和计算指标的五大囧人工评分工具。没有新增助手标注，没有把模型预测当真值，也没有要求用户亲自评审比赛。

## 1. 已测到的改善及其范围

固定六条此前未查看的测试片段，来自 VNL-STES 原测试比赛，共 35 个原动作事件；所有方法完成六条，无失败样本被删除。按动作类别进行最大一对一时间匹配，误差容许 ±0.5 秒，重复预测计入误报。

| 方法 | Precision | Recall | F1 | TP / FP / FN |
| --- | ---: | ---: | ---: | --- |
| Qwen3-VL-8B，原 2 FPS 视觉诊断基线 | 13.16% | 28.57% | 18.02% | 10 / 66 / 25 |
| 新训练的冻结 ResNet18 + 时序 GRU | 25.00% | 45.71% | **32.32%** | 16 / 48 / 19 |
| 原 YOLO 动作检测器，诊断对照 | 40.00% | 5.71% | 10.00% | 2 / 3 / 33 |

本地时序模型比该视觉基线提高 **14.31 个 F1 百分点**，精确率和召回率均提高。它仍有 48 个误报、未召回拦网；测试没有 score 正例，不能评价得分类召回。旧 YOLO 的上游训练比赛清单未知，其成绩只作诊断。

**这不是整场动作理解准确率，也不是五佳球或五大囧质量分。** 测试只有一场比赛、六条低清静音片段，尚未证明跨比赛泛化、动作成功与后果判断、解释正确性、前五主观质量或完整叙事剪辑质量；不计算具有误导性的跨比赛置信区间。

## 2. 数据隔离、真实训练和没有采用的实验

从 [VNL-STES 作者发布](https://hoangqnguyen.github.io/stes/)的原连续 JPEG 和原事件 JSON 采集数据。固定 ID 等距抽样，不根据动作数量或模型效果挑选：原六场训练比赛各八条，共 48 条、457.52 秒；原独立验证比赛六条；原测试比赛另取六条，并排除之前已经看过的五条测试片段。

训练仅使用原 train 标注；原 val 用于早停、阈值与时间 NMS 选择。48 条训练样本共 288 个原事件；训练 29 轮，在第 17 轮验证最佳。神经网络真实更新了时序头权重，骨干保持冻结。训练目标是原事件帧的确定性软化，原标签不修改。测试在配置冻结后执行，结果没有用于继续调参。模型、来源和冻结参数见 [本地排球动作定位](本地排球动作定位.md)，数据抽样与校验见 [排球动作数据隔离](排球动作数据隔离.md)。

并行比较过分块 8 FPS、实际帧引用、要求后续证据的视觉理解方案。每块最多 24 帧、保留重叠、用实际 PTS 映射预测时间，不让模型自行编造时钟；缺少后续画面时只能记未知。验证六条的 18 个分块全部请求完成，但 F1@0.5s 为 12.12%，低于完整完成的 2 FPS 基线 18.75%。因此该方案保留为实验工具，没有替换生产默认理解路径。

还验证了服务接受原生 `video/jpeg` 请求，并按 [vLLM 文档](https://docs.vllm.ai/en/latest/features/multimodal_inputs/)提供实际帧号、原 FPS 和关闭再次采样的参数。请求成功不能证明服务内部遵守这些参数，报告明确记录 `server_native_video_sampling_verified=false`。不能把提高请求帧率或换成视频字段直接称为准确性改善。

## 3. 接入事件理解：候选引导复核

已训练模型位于 `models/actions/vnl_resnet18_gru.pt`，其 manifest 和官方 ResNet18 骨干同目录。先对实际输入视频导出一次动作候选，再让两类集锦共用：

```bash
.venv/bin/python scripts/export_action_evidence.py input.mp4 \
  --output runs/action_accuracy/input_actions.json \
  --device cuda:3 --total-timeout 300 --max-cache-mib 2048

.venv/bin/python -m volleymole.run_match --video input.mp4 \
  --collection both --action-evidence runs/action_accuracy/input_actions.json \
  --output runs/match_with_action_hints
```

第二条命令沿用项目已有 API 配置；必须使用已经验证可接收所选音视频输入的模型。本轮动作诊断中的 Qwen3-VL 图像支持不能证明音频支持，GLM-5.2 的图像请求此前已失败，详见[公开数据验收记录](公开数据验收记录.md)。命令展示接入方式，不代表当前 API 配置已通过完整音视频理解验收。

已修复生产路径固定申请 8,192 输出 tokens、与当前服务 8,192 总上下文冲突的问题：新增 `--semantic-max-tokens`，默认 4,096；`--semantic-frame-width` 可限制每帧宽度，默认保持粗读 512、复核 768。两个参数进入请求和缓存指纹，改变任一项都会重新分析。它们不降低帧率或截断时间范围；小上下文服务还需缩短全场粗读块，并给较长复核选择足够容量的模型。

本轮真实生产调用检查使用 `--vision-model qwen3-vl-8b-instruct --semantic-modality frames --semantic-max-tokens 2048 --semantic-frame-width 224 --event-chunk-sec 3 --event-overlap-sec 0.5`，仍保留粗读 2 FPS、复核 8 FPS。原验证片段完成 2/2 次粗读和 1 次复核，0 失败，耗时 7.55 秒；5 个本地动作候选进入该路径。模型返回零个有效事件，系统保留空结果，不强行凑数。这只验证一次真实请求及严格格式接入，不能证明小图像的动作准确性或音频输入支持。结果见 [生产调用检查](../runs/action_accuracy/production_smoke/summary.json)，实际参数和不含密钥的响应记录同目录。

导出复用连续解码、分块骨干推理与重叠时序窗口，用真实 PTS 保存源时间。只接受经过实际 PTS 检查的 25 FPS 视频，其他帧率返回 `unsupported`；到达预算时返回 `partial`，只输出上下文已经形成的前缀。`complete` 表示全部视频帧已处理，音轨在视频前后延伸的容器区间不自动算已分析；无论状态如何都保留实际覆盖区间，缺失帧或无候选不能说成已排除某类动作。

入口验证视频实际 SHA256、时长、相对容器起点的时间约定、覆盖边界、类别与概率字段；模型指纹作为来源记录并核对各行一致性，导入时不重新运行模型或读取其权重。多局可使用 `--action-evidence-dir DIR`，文件名为 `<源视频 SHA256>.json`；未找到的素材明确报告 `not_found`。

候选影响粗读的注意位置，并为尚未被有效复核区间覆盖的位置追加局部过程复核；长回合因超长未复核时，不会连带丢掉其中的局部动作候选。候选没有独立事实证据 ID，不直接确认触球、动作成功或得分，也不直接加竞技分。语义模型仍需引用实际画面或声音。源候选文件内容变化会使语义缓存失效，双榜共用同一结果。

真实验证视频的导出已通过生产导入器：112 帧、4.48 秒、5 个待核实候选，见 [接入核验](../runs/action_accuracy/production_import_audit.json)。模拟 API 的集成测试另行检查候选到达粗读与复核、缓存复用和失效、超长回合的局部复核；模拟返回值不是训练或评测标签。这些检查证明接入可运行，尚未测得“局部模型候选 + 语义复核”组合的准确率改善，所以显式启用该分支。

## 4. 五大囧人工评分基准已可执行

完整规范见 [五大囧人工评分基准 v1](五大囧人工评分基准.md)。以整场比赛分区、匿名原速素材、每种音频条件至少三名独立评员为基础，提供 0–4 分行为锚点、未知原因、事实和“铺垫 → 意外 → 反应”时间段记录。

总体有趣度、入选适合度均为真人独立直接判断；意外反差、相关笑声、叙事完整性、同伴反应另行记录。疑似受伤、普通失误、无关笑声等单列，不让固定加权分变成人工真值。静音笑声保持未知，音频与静音由不同评员组评审。

工具已实现匿名视频裁剪、每位评员独立随机顺序的离线 HTML 页面、空表导出、导入校验、评分分歧、序数 Krippendorff α、按比赛汇总的前五质量与有完整参照时的 nDCG。无候选比赛仍保留，要求显式空榜；未完成与缺评不折算为零。不同系统的已评覆盖率不同，不能直接比较各自已知子集的均值。

可查看已生成的 [离线空白评分页面](../runs/public_benchmarks/blooper_human_v1_smoke/review_silent_01.html)。它采用一条真实静音验证片段检验播放包和表格流程，不表示该片段已经被认定为囧事。页面已通过脚本语法、初始化和空白导出检查；当前环境没有 Chrome，未完成真实浏览器交互检查。

**当前真人完成评分为 0 条，趣味质量指标均未知。** 已搜集的公开动作和集锦标签不能替代排球五大囧的真人判断；本轮没有招募、联系外部评员，也没有由助手填写评分。基准设计和工具已经完成，后续只有真实独立人评到位后，才可能报告五大囧的主观质量。
