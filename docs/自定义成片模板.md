# 自定义成片模板

一份 JSON 同时保存剪辑呈现与配音偏好。`run`、`match` 使用 `options`；成片后的 `meme-audio` 使用 `audio`。模板不保存视频路径、输出目录、模型位置、设备或 API 密钥。

## 导出、编辑、导入

```bash
volleymole templates list
volleymole templates show matchday
volleymole templates export matchday --name my-team --output my-team.json
# 编辑 my-team.json 后：
volleymole templates import my-team.json
volleymole run --video data/match.mp4 --ranker rules --template my-team
volleymole match --input-dir data/matches --ranker rules --template my-team
```

也可跳过导入，直接使用 `--template ./my-team.json`。导入默认存入当前工作目录的 `templates/`，该目录被 Git 忽略。跨目录使用时设置 `VOLLEYMOLE_TEMPLATES=/absolute/path/to/templates`；模板管理命令也接受 `templates --directory /path/to/templates list`。

同名文件不会被覆盖；导入时可用 `--name another-team` 改名。修改个人模板可以直接编辑本地 JSON。内置名称保留给项目自带的五套设计。

## 格式示例

```json
{
  "version": 1,
  "name": "my-team",
  "description": "我的球队 · 英文标题 · 1440p",
  "options": {
    "style": "lively",
    "design_suite": "custom",
    "art_theme": "manga",
    "title_template": "arena-en",
    "transition_style": "velocity",
    "quality": "1440p",
    "replays": true,
    "replay_speed": 0.5,
    "replay_review": "auto"
  },
  "audio": {
    "enabled": true,
    "max_cues": 2,
    "rms_db": -20,
    "duck_db": -3
  }
}
```

`version`、`name`、非空 `options` 必填，`description`、`audio` 可省略。字段名与命令行对应，将连字符换成下划线；不认识的字段和不合范围的值会报错。

| 选项 | 可用值 |
| --- | --- |
| `style` | `lively`、`classic` |
| `design_suite` | `matchday`、`atelier`、`sumi`、`aurora`、`archive`、`custom` |
| `design_language` | `zh`、`en`；用于完整套装 |
| `art_theme` | `default`、`manga`、`clay`、`papercut`、`ink`、`retro` |
| `title_template` | `legacy`，或 `editorial` / `arena` / `cinema` / `pop` / `minimal` 加 `-zh` / `-en` |
| `transition_style` | `fade`、`velocity`、`paper`、`ink`、`prism`、`film` |
| `quality` | `720p`、`1080p`、`1440p`、`2160p` |
| `replays` | `true` / `false`；控制是否插入慢回放 |
| `replay_speed` | `0.5`–`1.0`；默认 `0.6666666666666666` |
| `replay_review` | `auto`、`required`、`off` |
| `top_k` | `5`、`10`；省略时沿用入口默认数量 |
| `collection` | `highlights`、`bloopers`、`both` |
| `analysis_mode` | `auto`、`rallies`、`events` |
| `ranker` | `auto`、`rules` |
| `focus_player` | 关注的球衣号码 |

也支持 `replay_review_timeout`、`replay_review_concurrency`、`replay_scan_fps`、`replay_review_fps`、`replay_review_width`、`replay_max_expansions`，含义见 `run --help`。

完整套装统一决定插画、标题与转场；自由搭配时必须使用 `design_suite: "custom"`。`classic` 使用原版呈现，不接受 lively 的套装及单项设计。`replay_review: "off"` 关闭 API 复核，仍保留本地慢回放候选，关闭全部慢放请使用 `replays: false` 或命令行 `--no-replays`，此时也跳过自动回放复核。关闭慢放不能同时要求 `replay_review: "required"`。

## 切换与临时覆盖

优先级：**显式命令行参数 > 模板 > 程序默认值**。

```bash
volleymole run --video data/match.mp4 --ranker rules \
  --template my-team --quality 720p --output runs/team-preview

# 对已有运行切换模板，重做渲染
volleymole run --video data/match.mp4 --ranker rules \
  --template aurora --output runs/team-preview --rerun-from render
```

内置模板不绑定五佳或十佳，也不强制启用 API；运行目录中的 `run_config.json` 保存最终参数和模板快照。模板不会代替分析与复核所需的配置；改变排名、回放策略或输入时，相关阶段仍按现有缓存规则重新执行。

可把已完成运行的参数导出为模板，导出只保留受支持的参数与模板配音偏好，不复制密钥或本机路径：

```bash
volleymole templates export --from-run runs/my-match \
  --name my-team-v2 --output my-team-v2.json
```

## 同一模板控制配音

先准备包含音频素材与插入时刻的计划，格式见[本地混音](克制梗配音.md)；也可以由[API 选梗](梗使用条件与API导演.md)生成计划。然后读取相同模板：

```bash
volleymole meme-audio --video outputs/approved.mp4 \
  --plan data/meme-plan.json --template my-team \
  --output outputs/with-memes.mp4
```

| audio 字段 | 含义 |
| --- | --- |
| `enabled` | `false` 时复制原成片，保留原画面与原声 |
| `max_cues` | 配音数量上限，1–20；超出时拒绝处理，先修改计划 |
| `rms_db` | 统一配音电平，-36 至 -14 dB |
| `duck_db` | 配音期间现场声增益，-12 至 0 dB |

模板值覆盖计划的对应混音设置；未写入模板的设置保留计划原值。`meme-audio` 的 `--max-cues`、`--rms-db`、`--duck-db`、`--audio-enabled` / `--no-audio-enabled` 可以再次覆盖。音频报告记录实际设置，原计划文件不改写。

`run` / `match` 保存配音偏好，但不会自动执行配音或请求选梗 API。更换模板不自动改变已有计划中的梗、素材及插入时刻。
