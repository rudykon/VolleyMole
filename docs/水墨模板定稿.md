本机定稿包：`templates/bundles/sumi-v2.0.0.zip`；旁边保留同名解压目录、`sumi-v2.0.0.sha256`、验证报告和测试记录。目录约定见[模板目录](模板目录.md)。`preview.png` 是确认版示例，`manifest.json` 记录字体、依赖版本和逐文件 SHA-256。包内有完整字体、许可证、插画、转场、配置和当前应用源码快照。为使源码快照可以离线使用，保留了它配套的完整呈现素材。

定稿包已从最初的生成目录迁入模板库，压缩包及包内文件保持原样，SHA-256 不变。包内封存说明中的旧路径请以本文为准。

包内不包含比赛视频、比赛分析结果、模型、虚拟环境或 API 凭据。支持本项目的 Python 3.12 环境；视频剪辑仍需 FFmpeg 和已有模型，依赖版本保存在 `pyproject.toml`、`uv.lock` 中。仅做文件校验无需安装渲染依赖。

## 复用

当前工作区继续选择“水墨 / 墨间回合”即可使用已修改的模板。需要在日后代码更新后仍精确复用定稿版时，使用包内的 `sumi.py` 入口；它先检查包内文件，再使用包内源码与字体。显式追加的命令行参数仍可覆盖剪辑参数。

在当前项目根目录执行：

```bash
.venv/bin/python templates/bundles/sumi-v2.0.0/sumi.py --verify
.venv/bin/python templates/bundles/sumi-v2.0.0/sumi.py --preview outputs/sumi-v2-confirmed.png
```

单视频剪辑时，将原来 `python -m volleymole run` 替换为 `python /解压目录/sumi-v2.0.0/sumi.py run`，其余视频路径、排名、回放审查、模型和输出参数照旧。多视频使用 `match`。入口自动带入水墨模板配置及包内正文字体。

模板默认中文、1080 × 1920、开启回放、回放速度 2/3 倍，趣味音效预算保留为 2 处；五佳／十佳由任务参数决定。模板只保存表现形式和默认参数，每球回放区间与梗点仍须依据当次比赛审核。

迁移后先运行 `--verify`，再运行 `--preview`。后者在禁用系统字体候选的情况下重新绘制示例，并与确认版逐像素比较；字体、渲染依赖或像素不一致会报错。不要把预览输出到定稿包内部。

## 版本保存

这个版本保留为固定参照。新风格请另存新版本；打包脚本默认写入 `templates/bundles/`，拒绝覆盖已存在的同版本目录或压缩包。首次构建命令是 `.venv/bin/python scripts/freeze_sumi_template.py`。字体二进制随本地 ZIP 保存，Git / wheel 继续排除字体二进制；旧 `assets-v1` 公开素材包未被覆盖。
