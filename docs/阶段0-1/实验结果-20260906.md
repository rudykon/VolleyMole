# 2026-09-06 真实实验结果

## 当前结论

工程复现成立：三个真实机位 × 三种输入，GPU 推理及上游原样 `track_calculator` 均运行
完成。新引擎的所有帧号、可见性、球心像素与固定上游完全一致；重复运行的检测、轨迹、时间
映射和回合内容一致。**模型质量、回合质量及人工节时 Go/No-Go 尚未成立**，需独立真值。

原始工程输入是源视频约 60–72 秒的无重编码短片；保留原编码、帧顺序、音频和旋转元数据。
为保留编码，截取使用 stream copy，包含 edit list/关键帧 preroll 差异，不冒充已做帧准确
原片导出的产品能力。真实可解码帧数与容器 `nb_frames` 可能不同，计算使用实际解码帧。
源/片段 SHA-256、命令及媒体信息见 `experiments/stage0/samples/manifest.json`。

近原帧率使用片段的精确平均帧率有理数；目标 30 fps 仅为实验变量。上游未提供足以确认训练
帧率的材料，不能将此次结果直接当成生产代理帧率已确定。不缩放、不使用稀疏搜索/精扫。

## 引擎与媒体验证

- 同一 HEVC 30 fps 任务重复运行：`detections.csv`、`tracks.jsonl`、`time_map.csv` 的
  SHA-256 一致，`rallies` 列表一致（任务 ID 与运行时间按任务变化）。
- 实际 CUDA 节点 profile 证明运行了卷积等模型运算。CPU 形状处理节点单独记录。
  沙箱无 GPU 的负向运行被拦截为 `GPU_UNAVAILABLE`，未产生 CPU 检测。
- H.264/10-bit HEVC 代理逐帧映射与源解码 PTS 一致，输出是稳定连续 CFR。
  旋转归一后为 0°；音轨复制前后的音频数据 SHA-256 一致。
- 真实 FFmpeg 和 GPU 推理任务均成功取消、无成功标记，子进程退出。
  跨输出根目录的并发请求返回 `JOB_BUSY`，旧 ID 返回 `JOB_EXISTS`，原输出保留。
- 补齐已有引擎无法导入的 `write_tracks_jsonl` 导出；缺失预测帧不再从评估分母消失；
  IoU 相等且无唯一最大匹配时不再隐藏未命中真值。
