VolleyCut 的 seq9 灰度预处理、热力图轮廓解码及尾批行为抽取自前者的
`src/inference_onnx_seq_gray_v2.py`，提交 `637c217b6589be50eba77687d3f5fa5ca103c175`。
增加真实 PTS、候选分数、ROI、取消、错误和独立输出；数学预处理与解码经九组真实输入验证。
末批不足九帧时，上游使用前批历史却把前几个输出分配给尾帧；本轮保持此行为并单独记录局限。
变更此行为须使用新流水线版本并重做对照。

任务取消文件、原子状态写入、独立 worker 进程及进度节流模式参考后者的
`label_ui/jobstore.py`、`jobs.py` 与 `worker.py`，提交
`d9f506785c9ee4d41938383418a0fcabcd849797`。最小引擎按当前串行需求实现，不移植其
产品页面、篮球规则、复核或导出业务。

时间映射读取本机 FFmpeg 7 的 fps 实际读写帧日志，并核对编码后的逐帧 PTS。
实现依据：[FFmpeg 7.0.2 fps 日志与选择语义](https://github.com/FFmpeg/FFmpeg/blob/n7.0.2/libavfilter/vf_fps.c)。
未复制 FFmpeg 源代码；只调用本地可执行程序。FFmpeg 版本和构建选项保存于环境审计。
