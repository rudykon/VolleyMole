# 阶段 1：ROI、输入校验与 CUDA 回退策略加固

更新：2026-09-06。仅推进阶段 0/1；本轮是工程 progress，不是质量验收或 Go。
功能/架构合同未改动，固定上游与权重未改动，未实现界面、播放器、导出或附录功能。

## 已实现的修复

- 新增共享输入校验，拒绝 NaN/Inf、用布尔值冒充数值、错误配置类型、非法帧率、
  越界阈值及轨迹/回合最大连接时间不一致。目标帧率按有理数保存；`--no-proxy` 同时
  指定目标帧率会报错，不再默默忽略。任务内部深拷贝请求，调用方后续修改不会改变运行配置。
- ROI 使用旋转归一后输入像素坐标，保留浮点边界。允许简单凹多边形、顺/逆时针及
  重复首点作为闭合写法；拒绝自交、非相邻边相触、重复边、退化形状、非有限或越界顶点。
  不自动修补形状、不做球场识别。显式 ROI 不允许被 `roi_only=False` 静默禁用。
- 几何版本 1 / 轨迹与质量规则版本 3：检查整个连接线段是否在 ROI 内，包括相邻观测点
  和缺口插值，不能只检查两个端点或有限采样点。跨凹口连接切段，记录
  `connection_crosses_roi`；原检测不删改。该理由也进入可解释的疑似备用球质量标志。
- 插值时间仍只来自真实 PTS，保留足够小数精度以免舍入把点推到浮点 ROI 外；边缘距离
  与检测/连接共用同一几何定义。几何容差是数值计算容差，不是质量验收阈值。
- 预检与解码一致使用旋转归一后的尺寸，解码帧尺寸不一致明确失败；原片诊断路径对
  非直角旋转要求使用代理。manifest 新增 ROI 坐标空间/尺寸/版本、源旋转及起始 PTS。
- 输出目录、锁、进度及诊断写入故障返回结构化错误；新增 `IO_FAILED`，诊断落盘失败
  不掩盖主错误。成功标记在最后提交，避免后续进度写入失败却残留 `COMPLETED`。
  全文件指纹计算增加取消检查，清洗/插值过程也响应取消。

核心文件：`src/volleycut/validation.py`、`roi.py`、`jobs/engine.py`、
`perception/vballnet.py`、`tracking/clean.py`、`rallies/split.py`、`runtime.py`。
连续九帧灰度预处理、归一化、模型和固定上游尾帧处理未改变。

## 初始化阶段也禁止 CPU 重试

只在会话创建后调用 `disable_fallback()` 不足以阻止 ORT 构造函数先重试 CPU。
本机锁定的 ORT 1.24.1 实现支持 `enable_fallback=False`；现在创建会话时即传入，
并再次关闭、核验运行时回退开关。manifest 记录 `fallback_policy_version: 2`，
初始化和运行时回退均为 false。

核验依据为本机安装源码
`.venv/lib/python3.12/site-packages/onnxruntime/capi/onnxruntime_inference_collection.py`，
SHA-256：`da9148cb6e149ec737df5f836422e12f5951b68bdb93dbfb95af3906e10ee63d`。
未修改 ORT 安装文件。以后升级依赖须重新检查该选项和真实正/负向行为。

真实无 GPU 沙箱审计：`experiments/stage1/verification/no_gpu_strict_audit_20260906/report.json`。
`nvidia-smi -L` 返回 9，未设置设备隐藏变量；实际 CLI 返回 3 / `GPU_UNAVAILABLE`，
无 CPU 重试消息，ORT profile 中模型节点执行数为 0；无检测、轨迹、回合或成功标记。
stdout、stderr、设备探测、任务错误与 profile 均保留哈希。之前修复前的负向结果
`rules_v3_gpu_unavailable/` 也保留：曾触发构造阶段 CPU 重试，但引擎在推理前拒绝继续，
没有把该历史缺陷伪装为现行策略。
