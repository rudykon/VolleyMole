# 阶段 1：规则 v2、时间对齐与独立标注进展

本记录接续阶段 0 的真实实验，不替代冻结质量验收。阶段 0、1 均未完成；不得据此宣称 Go。

## 本轮实现

- `tracking/clean.py` 规则 v2：以源时间和画面宽度表达速度、加速度、方向变化及最短观测时长。
  修复旧规则“活跃轨迹”可绕过 300 ms 短缺口上限的问题。插值时间只能来自真实输入帧 PTS；
  丢失映射、过长缺口或运动冲突导致分段。孤立方向/加速度尖峰保留原检测，另记拒绝依据。
- `track_decisions.jsonl` 保存分段/拒绝原因，列入任务输出哈希；观测与插值状态不混淆。
- 回合质量规则 v2：按时间桶覆盖度代替固定帧数；使用实际 ROI 多边形边缘，而非只检查图像
  边框；源起始时间用于缓冲裁剪。静止点不独立构成运动证据，合并轨迹间的缺口参与标志。
- `time_alignment.py` v1：按真实源 PTS 对齐，不按相同帧号或最近帧猜测。重复采样源帧时，
  原生帧报告固定取第一次映射（不是第一次成功检出），未采样源帧保留在召回分母中；另报
  模型输入帧指标，明确两个统计总体。
- `gap_metrics.py` v1：正确、错误、无法验证的短连接分别统计；不可见或缺少真值的插值点
  不能算作正确。严格正确率包括未知项，已验证正确率单列并同时报告覆盖率；零连接不报 100%。
- 评估 CLI 目前只输出诊断指标，拒绝空帧标签/未审阅回合。尚非绑定冻结配置的正式验收入口。

所有数值为待独立基线检验的算法参数，**不是已经冻结或通过的质量阈值**。
