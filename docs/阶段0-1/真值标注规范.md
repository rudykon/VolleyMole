# 阶段 1 独立真值标注规范

数据材料：`data/validation_work/manifest.json`。它是未标注材料，**不是冻结验证集**。
三个固定机位源：`2.mp4`、`3.mp4`、`IMG_0171.MOV`；前两个机位方向不同，后一个为更远、
轻微倾斜的 10-bit HEVC/HLG 机位。初始各自 120–144 秒用于调参，240–264 秒用于验收；
窗口在查看对应推理前选定。`2_tuning` 因原片显示末尾仍在比赛，已扩展至 150 秒，
其余五个窗口暂未变动。扩展理由、原清单备份、交界处 3 帧同 PTS/同 PNG 哈希证据保留在
`2_tuning/context_to_150000/`；不缩短原窗口或移除难例。不可把调参窗口或本轮
60–72 秒工程对照窗口混入验收。

若窗口包含不完整回合或无完整回合，需查看相邻原始画面后扩展并记录选取理由，再冻结；
不能把窗口边界假定成发球/死球。验收需覆盖长短回合、可见/遮挡/出画、备用球干扰。

## 帧级

逐帧查看原尺寸 PNG 与邻帧；图像由真实源视频连续解码，归一旋转，不经检测模型。
`frames.csv` 的 `source_pts_ms` 来自同一次 FFmpeg 解码日志。`frame_idx` 是窗口内帧号。
在代理不缩放的当前实验里，坐标与旋转归一后的代理像素一致；评估其他帧率代理时用
`time_map.csv` 的源 PTS 对齐标签，不能直接按相同帧号对齐。

- `visible=1`：能明确定位比赛用球，填写球心 `x/y`（原尺寸像素）。
- `visible=0`：球不可见，`x/y` 留空；不能因检测器没检出而填 0。
- 无法判定时保持空白并填写 `notes`，复审前不得冻结。
- 多球时只标比赛用球，记录备用球；不得把亮点当球。每行填写实际标注者和必要说明。
- `overview.jpg` 仅用于导航，不能用稀疏缩略图替代逐帧标注。

允许使用独立的颜色/几何裁剪作为定位测量提示，但不能自动接纳。每个球心必须单独查看
原尺寸裁剪与邻帧，错误目标、偏心、缺失提示均须回到原始图片；没有提示不代表不可见。
`prepare_visual_review.py` 不读取 VBallNet/轨迹/自动回合，也不写标签。审阅批次单独保存
采纳帧号、人工式视觉修正、原图辅助材料 SHA-256 与未解决帧号；这些提示不是第二个
生产检测器。助手初标须记录估计定位误差，模糊或局部遮挡标签在冻结前仍需复查。

## 回合级

独立查看视频运动与结束依据，不从球坐标、轨迹或自动回合推导标签。
逐回合填写 `rallies.json` 的整数 `start_ms/end_ms`、发球与结束证据帧、标注者。
开始为发球球离手下一帧；难判断时为首次明确进入比赛运动的帧。结束为落地、出界、死球或
裁判鸣哨使回合结束的帧。边界上下文有疑问必须记录并复审。

空 `rallies` 配合 `unreviewed` 不代表“真实无回合”；只有独立复审确认的空片段才能作为负例。
双方标注可以来自同一审阅者，但必须单独查看与记录，不互相派生；助手视觉标注须明确署名，
不可冒称用户或人工双人复核。

## 冻结与质量门禁

所有窗口逐帧标签完整、回合证据完整、源/图片哈希通过，调参与验收互斥，才可设置冻结。
冻结包保存标签 SHA-256、匹配脚本版本和评估范围。首次独立真值基线后制定并锁定验收配置；
本轮不拿检测数量或上游一致性作为准确率，不提前填写“已通过”的质量阈值。

人工复核节时还需要用户实际计时；助手运行耗时不能替代该指标。
