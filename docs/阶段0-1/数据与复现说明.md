# 本地数据与复现说明

本仓库上传源码、测试、操作说明和必要的第三方许可；**不上传任何用户素材、实际标注或实验数据**。
现有 Web 界面与 HTTP 服务骨架保持独立，阶段 0/1 引擎尚未与其集成。

## 不随仓库发布的内容

- 原始视频、音频、代理视频、逐帧图片及审阅截图。
- `data/` 中的 CSV/JSON 标签、回合边界、材料清单、源视频指纹和本地路径。
- 检测/轨迹输出、运行 manifest、性能 profile、日志、JUnit 报告和检查点快照。
- 模型权重、第三方完整工作树、虚拟环境、缓存及所有凭据。

这些内容均保留在原本的本地目录中，不会因为本次同步而被删除。请勿使用 `git add -f`
将其加入公开仓库；`.gitignore` 已排除数据目录和生成产物。

## 帧级标签格式

帧级 CSV 的字段约定如下；这里只说明字段，不提供实际数据行。

| 字段 | 含义 |
| --- | --- |
| `frame_idx` | 独立片段内的帧号 |
| `source_pts_ms` | 从真实解码日志取得的源时间戳 |
| `image` / `image_sha256` | 本地原尺寸图片路径与完整性哈希 |
| `visible` | 1 为能定位比赛用球；0 为经原图确认不可见；空白为待定 |
| `x` / `y` | 旋转归一后原尺寸像素球心；不可见或待定时留空 |
| `annotator` / `notes` | 实际审阅者、疑点和依据 |

每帧都须独立查看原图与邻帧。颜色裁剪只能辅助导航，提示缺失不能生成不可见标签；
不能用插值、检测器输出或轨迹结果填充真值。模糊、局部遮挡或备用球混淆保持待定。

## 回合级标签原则

回合边界单独查看源画面，不从球心坐标序列或自动回合派生。开始为发球手球分离后的
下一帧，难判断时采用首次明确进入比赛运动的帧；结束须有落地、出界、死球或明确哨声依据。
身体放松、球出画、检测中断与窗口终点本身都不能证明结束。空回合列表配合 `unreviewed`
不代表已经确认的负例；截断片段需要相邻原片上下文。

## 本地运行与测试

先按 [引擎指南](../../README_ENGINE.md) 安装独立 Python 3.12 环境；自行准备有权使用的
视频和模型，通过 CLI 的 `--video` / `--model` 参数传入本地路径。默认使用 CUDA，后端
不可用时明确失败，不静默回退。模型代码许可与权重分发许可分别核查。

无需私有素材的测试可按引擎指南运行 `-m 'not local_data'`，覆盖全部公开工程测试。
`local_data` 标记真实媒体和标注材料检查；直接运行全套或显式选择这些检查时，缺失材料
会失败，不会自动跳过。不能据此虚构通过记录，也不能拿合成测试替代真实视频质量或用户计时。
测试分层见 [回归测试与 CI](回归测试与CI.md)。历史实验脚本和完整报告不属于公开同步范围。
