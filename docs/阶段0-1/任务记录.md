## 执行次序

1. 固定上游/权重/环境证据；真实视频验证 CUDA 算子执行和上游原样流水线。
2. 修复最小引擎：真实逐帧 PTS、连续九帧一致性、进度/取消、串行任务与隔离、错误和复现。
3. 至少三个代表性固定机位：原始连续帧、接近原帧率代理、目标固定帧率代理；原样轨迹规则
   不传球网/球场标定，单独报告局限。目标帧率仅作为实验变量，不提前认定为生产选择。
4. 分开调参/验收片段，独立逐帧位置与可见性标注、回合边界标注，冻结哈希。
5. 修正评估逻辑，基线后冻结版本化阈值；报告模型质量和节时 Go/No-Go。
