## 运行环境要点（与模型配套冻结）

- ONNX Runtime 1.24.1（`onnxruntime` 包，CUDAExecutionProvider）。
- 依赖：CUDA 12.x 运行时（系统 `/lib/x86_64-linux-gnu/libcudart.so.12`）+
  cuDNN 9.x（venv 内 `nvidia-cudnn-cu12==9.25.1.1`，经 `LD_LIBRARY_PATH` 或
  引擎内置预加载暴露）。缺 cuDNN 时 ORT 会**静默回退 CPU**，引擎预检必须拦截。
- 推理输入为九帧灰度序列（seq9），预处理：BGR→灰度→resize 288×512→/255，
  与上游 `src/inference_onnx_seq_gray_v2.py` 完全一致，不得更改。
