# 模板目录

所有模板统一归入项目根目录的 [templates/](../templates/README.md)，命令行与网页共用同一套目录规则。默认位置由项目位置确定，不随启动命令时的工作目录改变。

| 位置 | 内容 |
| --- | --- |
| `templates/builtin/` | 五套内置 JSON 预设，随应用发布 |
| `templates/custom/` | 个人 JSON 预设；命令行导入和网页保存均写入这里 |
| `templates/bundles/<版本>/` | 定稿包解压目录，固定字体、素材、配置及源码 |
| `templates/bundles/<版本>.zip` | 完整备份包 |
| `templates/bundles/<版本>.sha256` | 压缩包校验值 |
| `templates/bundles/<版本>.validation.json`、`.tests.log` | 验证报告与测试记录 |

本机水墨确认版为 `sumi-v2.0.0`，使用方法见[水墨模板定稿](水墨模板定稿.md)。通过其解压目录中的 `sumi.py` 入口复用；新风格另存新版本。打包脚本 `scripts/freeze_sumi_template.py` 默认写入 `templates/bundles/`，拒绝覆盖已有版本。

内置配置已从 `src/volleymole/templates/` 迁入 `templates/builtin/`；已有个人配置已归入 `templates/custom/`。旧版根目录平铺的个人 JSON 仍兼容读取，新保存统一使用 `custom/`。样片与临时预览仍保存在 `outputs/`，水墨封存包中的历史源码不改写。

`builtin/` 和目录说明随 Git 分发，`custom/`、`bundles/` 保留在本机。可通过 `VOLLEYMOLE_TEMPLATES` 或模板管理命令的 `--directory` 显式指定整座模板库；网页以当前工作区的 `templates/` 为根。独立安装应用时默认使用 `$XDG_DATA_HOME/volleymole/templates/`（未设置则为 `~/.local/share/volleymole/templates/`），首次使用将内置预设放入其 `builtin/`，不覆盖已有文件。

JSON 预设的参数格式与导入方式见[自定义成片模板](自定义成片模板.md)。
