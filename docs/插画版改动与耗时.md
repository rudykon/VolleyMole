# 插画版改动与耗时

日期：2026-09-09。本文记录历史设计修订号 2，成片现保留为 `runs/1-top5/top5_lively_v2.mp4`。当前默认输出已增加中文名次横幅、多动作插画与用户提供的品牌标志，见 [名次与品牌版改动与耗时](名次与品牌版改动与耗时.md)。

## 四项修改

- 快切片头延长到 **5 秒**：五个精彩片段各 1 秒。
- 标题使用站酷快乐体、轻微倾斜和手绘式装饰线，替换此前的常规黑体标题。
- 去除画面上的 `#1` 等数字名次牌，改用三张由 **Codex 内置生图**生成的透明排球插图，以及“精彩开场／好球接着来／压轴登场”提示。内部剪辑单仍保留排名以便追溯。
- 每次转场为 **3 秒**，约 0.4 秒淡入、**2.2 秒完整展示**全屏插图和下一回合标题、0.4 秒淡出。插画标题卡独立于比赛动作，不裁断回合。

三个原始透明 PNG 已从 Codex 生成目录复制到项目 `tools/volleyball-top-plays/assets/illustrated/`，原始文件保留。按 imagegen 技能使用内置工具，没有切换到 CLI/API 生图。具体素材和完整最终提示词见 [素材说明](../src/volleymole/assets/README.md) 与 [提示词清单](../src/volleymole/assets/illustrated/prompts.json)。字体来源和许可证也保存在素材目录。

五段完整回合及五次短慢回放保持不变。成片总长 **137.5 秒（2 分 17.5 秒）**：比赛回合 102.5 秒 + 片头 5 秒 + 回放 15 秒 + 标题转场 15 秒。格式为 720×1280、30 fps、H.264/AAC，共 4,125 帧。

```bash
  --video data/样例视频/1.mp4 --top-k 5 --style lively
```
