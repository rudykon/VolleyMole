## 自动化范围与画面修正

复用了经过 SHA256 绑定的原有回合、排名和跟球轨迹缓存，12 份原视频均已核对；此次没有从零重跑整场本地分析。十佳球沿用每一天既有的十球排序，五大窘由 API 候选加助手视觉核对选定。此前获用户认可的四球回放复用了原始区间和来源绑定，不新增 Gemini 请求。

便宜模型仍会把二传、吊球识别为强扣，也出现跌倒、卡网和触球位置的错误描述。本批逐段检查了原始画面，修正回放窗口，省略无法确认的回放；不是每球都强行慢放。1 月 6 日五大窘另外修正了三段镜头，让追球、坐地和蹲下的当事人保持在画面中。新镜头控制数据明确标记为助手设置，原始球检测另存。

因此，**本批是 API 辅助、助手复核后完成的成片，不是“换任意视频即可无人复核稳定达标”的通过证明**。`assistant_checks.json` 中保留了助手判断、来源和证据，不冒充人工真值或模型自身通过。

配音条件继续执行“开炮只用于明确势大力沉的扣球”和完整语句要求。本批没有满足完整时机条件的可用梗配音，8 部均保留原声，新增梗配音为 0。没有把二传、吊球误判结果交给配音，也没有截半句音频凑数量。

## 低费用 API 与传输修复

梗导演默认模型已从 Gemini 调整为 `qwen3.5-35b-a3b`，使用兼容 Chat 接口，输出预算为 8192。不自动回退到昂贵模型。结构化约束也写入提示词，解决网关将 `json_schema` 降为 `json_object` 时丢失字段说明的问题。

新增通用 Chat SSE 接收模块，用于本批长请求诊断：保留内容增量与用量，丢弃推理文本；必须同时收到正常结束、`[DONE]` 和干净流结束，才接受 JSON。输出超限、截断、异常事件均拒绝。此流式路线仅完成实验接入，尚未替换所有正式 Chat 请求。

本批记录 243 次请求预占，含失败、重试和模型对照，其中 Qwen3.5-35B 为 214 次，Gemini 为 0 次。197 次返回完整用量，按公开单价估算为 **$0.6923**；另有 46 次缺少完整用量。这不是账单总额，未计未知用量，也未扣缓存优惠。逐模型调用和价格来源见本地交付说明及 `cost_accounting.json`。

API 授权覆盖四天全部视频。实际上传主要是候选区间抽样帧，另有两段 7 秒、8 秒的无声短片用于视频输入对照，没有上传整场录像或音频。

实测把服务失败和模型理解错误分别记录：

- Qwen3.5-35B 有可用结构化输出，但动作事实判断尚不可靠；更大的 Qwen 对照仍有二传/吊球误判，不能据价格更高推断合格。
- `moonshot-kimi-k2.5` 返回 `no_available_channel`，属于服务端通道问题。
- 若干长非流式请求在连接阶段或等待输出时中断。Kimi K2.6 流式对照一条完整返回，另一条达到输出上限，后者拒绝入片。
- 没有将截断回答、失败请求或助手修正伪装成模型通过。
